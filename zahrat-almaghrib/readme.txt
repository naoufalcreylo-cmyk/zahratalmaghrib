Arabic-first editorial block theme for زهرة المغرب — مجلة إلكترونية نسائية متخصصة.

== Description ==

A native block theme (theme.json, templates, template parts, patterns) with:

* Genuine RTL built on CSS logical properties; French posts render LTR automatically.
* Self-hosted Noto Kufi Arabic (headings), Noto Naskh Arabic (reading) and Noto Serif (French).
* Editorial homepage blocks: lead stories (manual → sticky → latest), latest articles with real
  pagination, category sections in five layouts, editors' selection, labelled ad slots — with no
  story repeated on the same page.
* Long-form article template: breadcrumbs, standfirst, byline with updated date, captioned
  featured image, optional table of contents, share links, author card, comments, related articles.
* Complete Arabic interface (languages/ar.mo + editor JSON).

The theme never creates, edits or deletes content on activation and outputs no SEO metadata or
structured data, leaving those to the site's SEO plugin.
